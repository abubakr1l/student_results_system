# Student Results Management System

A console-based JavaScript assignment using Object-Oriented Programming and modern array methods.

## Technologies
- HTML5
- CSS3
- JavaScript (ES6)

## Requirements covered
- `Student` class with `id`, `name`, `grades`, and `attendance`.
- `calculateAverage()` uses `reduce()`.
- `getGrade()` uses `if/else` to return A, B, C, D, E, or F.
- `getFinalResult()` uses `&&` to check average >= 50 and attendance >= 75.
- `studentsList` contains four students, including students with averages from 40 to 49.
- `filter()` selects eligible students; `map()` adds five mercy marks; `reduce()` sums revised averages.
- A zero-length check prevents division by zero.
- `console.table()` and `console.log()` display the reports in the browser console.

## Grade scale
The assignment does not specify grade boundaries. This project uses A: 90+, B: 80+, C: 70+, D: 60+, E: 50+, and F: below 50.

## Run
Open `index.html` in a browser, then open Developer Tools and select Console to view the output.

## Files
- `index.html` — page and instructions.
- `script.js` — class, sample data, calculations, and console output.

Review the sample names and grades before submission. Keep four students and at least one original average between 40 and 49.
